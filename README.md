# 点点互动笔记 Demo

静态交互原型，包含三个独立方案：

- 方案1：上下滑动，新疆十日游封面。
- 方案2：左右滑动，伊犁大环线封面。
- 方案3：苏州三日游全屏对话笔详。双列流封面使用 Figma 1683:50113，笔详和点点阅读页使用 Figma 1687:50216。

方案1保留原来的卡片高度。常规态上下滑动先浏览卡片里的对话，再衔接笔记正文和评论，上下操作栏始终显示。轻点卡片进入独立的点点对话页，点击内容不会退出，上下阅读也不会露出笔记正文与评论；通过返回键回到笔详页。轻点半露卡片时先回到完整卡片的位置，再进入对话页。

方案2按新版 Figma 2259:16499 调整：内容图片区保持3:4，393px宽时完整阅读视口高524px，不再扣除底部按钮和分页点的高度。手机端随宽度等比计算；分页点在图片区外独立占24px。查看完整对话按钮悬浮于右下角，距右侧和底部各10px，高36px、字号13px，使用Figma导出的18px展开图标；保留原按钮文案，宽度随文案自适应。文字可跨页，图片组件保持完整，气泡按内容高度收尾。方案1、3的尺寸和按钮不受影响。

方案2轻点卡片进入小红书样式的黑底图片查看页：左上关闭、顶部页码、图片居中，左右滑动翻图。按当前卡片页进入，关闭后同步看图页选中的页码并保留笔详滚动位置。只有点击“查看完整对话”才进入点点对话页，接续当前内容。图片查看页不带对话流、追问入口或可点击的原卡片控件。浏览器返回先关闭图片查看页，不直接回到双列流。仅调整方案2；方案1和方案3的展示及进入对话行为不变。

从双列流点击对应笔记进入体验。仅演示交互，不连接真实 AI 服务。

三个方案的封面共用方案3的393×524排版：大标题、四项内容tag、手机容器中的对话页截图。截图复用实际对话页的内容、气泡和头部样式，按393→345等比缩小后裁切，不单独重排气泡。方案1和2的截图及tag完全相同，只更换封面标题；方案3展示苏州对话。卡片标题上方不再展示“点点ai对话”标识。封面变化不影响各自的阅读链路。

方案3从右列的苏州封面卡片进入。笔详只展示固定的苏州对话首屏，铺满作者栏与底部互动栏之间，预览本身不能滚动；上滑直接露出笔记正文和评论。方案1、3的“查看完整对话”采用 Figma 1687:50966 的底部居中白色胶囊按钮，40px 高、14px 字号、20px 标识容器与原尺寸 SVG，配合底部渐变遮罩；方案2使用上文所述新版右下角按钮。点击缩放展开为点点阅读页，并接续当前阅读位置。两处共用同一套 Figma 对话结构、间距及图文素材。阅读页的“我也问点点”参考 IMG_0021.MP4，使用同款胶囊按钮，固定底部居中，沿用推荐问题、选择问题进入新对话的链路。退出方案3后恢复新疆内容与推荐问题。相关样式与状态单独放在 poster.css / poster.js，不改变方案1、2的阅读手势和尺寸。双列流封面仍按393×524设计坐标渲染；字体使用本机苹方回退。

使用 GitHub Pages 从 main 分支根目录发布。

### 2026-11-11 全屏详情预览蒙层

方案3详情页按 Figma 2269:4982 增加底部217px渐进模糊和浅色渐变蒙层；按钮高44px，距预览底部30px，使用本次设计稿导出的点点标识。渐进模糊用六层羽化背景模糊近似，兼容 WebKit 前缀。蒙层不截获手势，仍可上滑浏览笔记正文和评论；仅“查看完整对话”按钮进入清晰阅读页，关闭后恢复原详情位置与蒙层。蒙层不会复制到完整对话或个人对话内容中，也不影响方案1和方案2。

手机兼容：封面 tag 之间的细线使用 CSS 绘制，避免小尺寸 SVG 在手机浏览器中显示破图。方案3使用原生纵向笔记滚动，可从固定首屏继续上滑到正文和评论；方案1的自定义嵌套滚动手势不应用于方案3。


### 2026-10-23 动效与个人对话页

- 三个方案从笔详进入完整对话时，作者栏向上收起、底部笔记信息和操作栏向下收起；正文保持原字号并接续阅读位置。退出时反向恢复。双列流进入笔详的缩放动效保持原样。
- 点击「我也问点点」进入个人对话页，先横向进入，再平滑接到回答末尾；显示「聊聊新话题」、欢迎气泡和三条可点击推荐问题。
- 输入栏采用语音、相机和加号的组合，下方显示「内容由AI生成」。进入时不自动聚焦或弹出键盘；点输入栏后才显示演示键盘。
