# 点点互动笔记 Demo

静态交互原型，包含两个方案：

- 方案1：上下滑动，手机对话封面。
- 方案2：左右滑动，大字封面。

方案1保留原来的卡片高度。常规态上下滑动先浏览卡片里的对话，再衔接笔记正文和评论，上下操作栏始终显示。轻点卡片进入独立的点点对话页，点击内容不会退出，上下阅读也不会露出笔记正文与评论；通过返回键回到笔详页。轻点半露卡片时先回到完整卡片的位置，再进入对话页。

方案2支持轻点卡片切换清屏，清屏时隐藏作者栏、底部互动栏和“查看完整对话”。常规态给按钮和分页点预留独立区域，首屏即可看到；清屏态按整屏可见高度重新分页，通过内容锚点衔接阅读位置。文字可跨页，图片组件保持完整，接近页尾时允许等比例缩小整组方形缩略图。气泡按内容高度收尾，不强行拉长。

方案2两种状态均可左右翻页。清屏上滑时，快滑直接进入笔记正文与评论；慢拖超过屏高五分之一后松手进入，否则回落。点击半露卡片回到清屏状态。这是笔详页内的清屏交互；“查看完整对话”打开的点点对话页始终与笔记正文和评论分开。

从双列流点击对应笔记进入体验。仅演示交互，不连接真实 AI 服务。
