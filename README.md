# 点点互动笔记 Demo

静态交互原型，包含三个独立方案：

- 方案1：上下滑动，新疆十日游封面。
- 方案2：左右滑动，伊犁大环线封面。
- 方案3：苏州三日游全屏对话笔详。双列流封面使用 Figma 1683:50113，笔详和点点阅读页使用 Figma 1687:50216。

方案1保留原来的卡片高度。常规态上下滑动先浏览卡片里的对话，再衔接笔记正文和评论，上下操作栏始终显示。轻点卡片进入独立的点点对话页，点击内容不会退出，上下阅读也不会露出笔记正文与评论；通过返回键回到笔详页。轻点半露卡片时先回到完整卡片的位置，再进入对话页。

方案2使用与方案1相同的笔详卡片尺寸：电脑端高524px，手机端按宽度的4/3计算，限制在450–570px。卡片内左右翻页，按钮和最多五个分页点保留独立区域。文字可跨页，图片组件保持完整，气泡按内容高度收尾。

方案2轻点卡片或“查看完整对话”直接进入点点对话页，定位到卡片当前可见的内容，不再进入图片清屏状态。对话页只展示连续对话和追问入口，上下阅读不会露出笔记正文或评论；返回后保留原卡片页码和笔详滚动位置。笔详内上下滑动仍可浏览正文与评论，上下操作栏保持显示。

从双列流点击对应笔记进入体验。仅演示交互，不连接真实 AI 服务。

三个方案的封面共用方案3的393×524排版：大标题、四项内容tag、手机容器中的对话页截图。截图复用实际对话页的内容、气泡和头部样式，按393→345等比缩小后裁切，不单独重排气泡。方案1和2的截图及tag完全相同，只更换封面标题；方案3展示苏州对话。卡片标题上方不再展示“点点ai对话”标识。封面变化不影响各自的阅读链路。

方案3从右列的苏州封面卡片进入。笔详只展示固定的苏州对话首屏，铺满作者栏与底部互动栏之间，预览本身不能滚动；上滑直接露出笔记正文和评论。三个方案的“查看完整对话”均采用 Figma 1687:50966 的底部居中白色胶囊按钮，40px 高、14px 字号、20px 标识容器与原尺寸 SVG，配合底部渐变遮罩。点击缩放展开为点点阅读页，并接续当前阅读位置。两处共用同一套 Figma 对话结构、间距及图文素材。阅读页的“我也问点点”参考 IMG_0021.MP4，使用同款胶囊按钮，固定底部居中，沿用推荐问题、选择问题进入新对话的链路。退出方案3后恢复新疆内容与推荐问题。相关样式与状态单独放在 poster.css / poster.js，不改变方案1、2的阅读手势和尺寸。双列流封面仍按393×524设计坐标渲染；字体使用本机苹方回退。
