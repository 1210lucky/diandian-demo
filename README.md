# 点点互动笔记 Demo

静态交互原型，包含两个方案：

- 方案1：上下滑动，手机对话封面。
- 方案2：左右滑动，大字封面。

方案2支持轻点卡片切换清屏，清屏时隐藏作者栏、底部互动栏和“查看完整对话”。两种状态均可左右翻页，页码与内容裁切保持不变。清屏上滑时，快滑直接进入正文与评论；慢拖超过屏高五分之一后松手进入，否则回落。点击半露卡片回到当前页的清屏状态。

方案2按接近手机全屏的高度分页。常规态可上下浏览长卡片，“查看完整对话”吸附在可见区域底部；清屏后卡片铺满大部分屏幕，只保留少量边距和底部页码。

从双列流点击对应笔记进入体验。仅演示交互，不连接真实 AI 服务。

使用 GitHub Pages 从 main 分支根目录发布。
